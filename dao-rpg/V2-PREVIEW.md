# 道學群島 2.0 —— admin 專屬體驗改版

## 改版動機
舊版雖有角色移動，實際為島嶼背景圖＋編號節點＋選擇題。這次先以「可玩的場景」改善體驗，而不是只更換按鈕顏色。

## 新增內容
- 全新世界選擇畫面，四島使用原本的場景插畫，呈現個別色彩與氛圍。
- 可橫向捲動的探索場景；角色可使用鍵盤 A / D、左右方向鍵或手機左右按鈕移動；點擊 NPC 可自動走近。
- 場景中的島民、建築、石燈、樹木、智慧光點；鏡頭跟隨玩家移動。
- NPC 劇情對話／生活抉擇／獲得智慧卡／探索進度。
- 三階段終章：時機定心、情境辨析、書寫願行。
- **完整保留四部經典的 39 個章節與既有進度格式**，在原本 admin 的遊戲 iframe 內運作。
- 預覽版可從「經典圖鑑與舊版」切換回原版，仍可玩舊有的地圖玩法。

## 狀態與限制
- 目前仍為 **admin 專用體驗預覽**：其他會員不顯示入口，也不開放功能。
- 畫面、角色為程式繪製的 2D 概念稿，還不是正式高解析角色動畫素材；NPC 場景可進一步擴充。
- 核心劇情仍以原創生活情境與三選一抉擇為主，不代表已製作完整 ARPG 戰鬥機制；往後可追加動作、探索解謎、裝備、NPC 分支與多種關卡。
- 目前瀏覽器本機存檔（由父 APP 接收、依匿名會員雜湊分區）；未啟用 Firebase 跨裝置同步。
- 佛規和經典內容仍待崇正核定版本審閱，沒有將遊戲改編冒充經文原句。

## 驗證
已在 Chromium 的桌機、手機模擬尺寸測試：四島入口、場景、角色移動、NPC 對話、錯誤答案重試、智慧卡獎勵、進度增加、前往下一關、三階段 BOSS、完成願行，以及 sandboxed iframe 隔離存檔訊息。不等於已在所有 iOS/Android 實機驗收。
