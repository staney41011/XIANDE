## 專案目標

1. 面對初次認識崇正、賢德的新朋友，提供溫暖、可靠、易懂的第一印象。
2. 用「探索一座成長之島」呈現團隊、班期、服務、文化和活動之間的關係。
3. 讓使用者自然走過「認識我們 → 探索活動 → 看見故事 → 找到參與方式」。
4. 手機友善，桌面可投影；保留沉浸式島嶼特色，避免變成制式商業 Landing Page。
5. 現有主系統 `XIANDE/index.html` 與前端、後端、PWA、果園、經典功能不受影響；僅修改 `heart-island/`。

## 專用設計系統（依原始 Skills 的精神，為本專案調整）

### 版面與敘事

- 首屏聚焦一句有情感、易理解的主標，以及一個明確的「開始探索」操作。
- 讓島嶼成為視覺主角，導覽卡片和文字應退居配角，避免大量資訊疊在地圖上。
- 建築點擊後的內容層級：主題 → 一句介紹 → 真實活動故事／照片 → 相關參與方式。
- 區塊尺寸與留白需要形成節奏；避免三欄等寬卡片反覆堆砌、重複說明或廉價模板感。
- 介紹文案使用實際可查證的班期／活動資料，示範內容應標明「示範」；不編造人名、日期、參與人數或具體成果。

### 色彩與字體

- 保留溫暖、清新、帶有成長感的主視覺，以奶油白、柔和綠、清爽藍與少量暖橘做搭配。
- 背景視覺可使用有意義的自然天空漸層、光影與環境深度；這是「島嶼場景」的藝術表現，與一般商業卡片上的濫用漸層不同。
- UI 面板儘量採簡潔單色表面、單一視覺重點、統一陰影光源。
- 中文以易讀繁體中文字體（如 Noto Sans TC）為優先；不要為了遵守英文字體清單犧牲中文可讀性。
- 建立固定文字階層與間距 Token，避免每張卡片各有不同字級、圓角、行距。

### 動畫與互動

- 互動動畫要有分量且自然減速，優先使用 `transform`、`opacity`，避免大量改動 layout 屬性造成卡頓。
- 開場、建築點擊、詳細內容展開、導覽切換要有一致的動態語言，避免同頁每個元素效果不同。
- 支援 `prefers-reduced-motion`、清楚的鍵盤 focus 樣式、可操作的手機觸控區域。
- 保留島嶼拖曳縮放，但增加清楚的「重置視角／開始探索」提示；手機避免手勢和頁面操作衝突。
- 所有按鈕需有 hover、active、focus；需要非同步讀取的部分應有 loading、empty、error 狀態。
- 動畫不應阻礙內容載入及導覽，手機效能比華麗程度更重要。

### 真實感與完整性

- 優先使用已授權的真實團隊照片、活動短片和實際文字；不以假人物、假統計充門面。
- 完整檢查圖片替代文字、頁面語意、返回動線、404、分享標題與圖片（OG）、favicon。
- 公開資訊不得顯示個人聯絡資料、團隊內部明細或尚未核實的資訊。
- 保持 GitHub Pages 可用：相對路徑、無需登入的靜態資產；絕不在前端公開 API token。

## 目前 `heart-island/index.html` 初步程式檢視（2026-10-28）

### 已有
- 獨立單頁 HTML，避免干擾賢德志士主系統
- 等角島嶼探索、導覽與點擊資訊視窗
- `100dvh`、`:focus-visible` 與 `prefers-reduced-motion`
- `<title>` 與 meta description

### 值得優先改善（尚未變更）
1. **品牌敘事**：第一眼除了漂亮島嶼，需更快理解崇正與賢德以及可參與的活動。
2. **視覺一致性**：統整目前細碎字級、圓角、間距和過渡動畫，建立固定 Token。
3. **操作體驗**：手機地圖操作、點擊區域、面板佔比與返回動線需要真機檢查。
4. **分享完整度**：加上 OG 標題、描述、分享主圖與 favicon。
5. **照片與故事**：目前為示範內容，正式版須替換成授權素材、審定文案。

## 改版流程

1. 先檢查現有版面、功能與素材缺口，列出問題，不盲目重做整站。
2. 先調整首屏、Typography／Spacing Tokens 和重要操作入口。
3. 接著調整細節頁面、手機版、動畫與無障礙操作。
4. 測試桌面與手機操作，修正異常後再更新 GitHub Pages。
5. 不更動原版的登入、果園、活動、經典閱讀及 PWA 檔案。
